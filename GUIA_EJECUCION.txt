GUIA DE EJECUCION - BOT SHIFTLABORAL
=====================================

1. INSTALACION (una sola vez por computador)
---------------------------------------------
1. Instalar Python 3.9 o superior.
2. Abrir una terminal en la carpeta del proyecto y correr:

     python -m pip install -r requirements.txt
     python -m playwright install chromium


2. EJECUTAR FASE 1 - Busqueda y comparacion (solo lectura)
------------------------------------------------------------
Este modo NUNCA modifica nada en ShiftLaboral, solo compara y genera un
reporte.

Opcion recomendada - un solo doble-click:
  1. Doble-click en ejecutar_bot.bat
  2. Se abre Chrome en un perfil separado y navega a ShiftLaboral. Si es la
     primera vez, inicia sesion manualmente con tu usuario y contrasena (el
     bot nunca ve ni guarda tu clave). Si ya habias iniciado sesion antes,
     solo confirma que la pagina cargo bien.
  3. Presiona una tecla en la consola para continuar.
  4. Arrastra tu Excel de entrada a la consola y presiona Enter.
  5. El bot corre solo. Al terminar, revisa reporte.xlsx en la misma carpeta.

Opcion manual (equivalente, si quieres mas control):

  "C:\Program Files\Google\Chrome\Application\chrome.exe" --remote-debugging-port=9222

  Inicia sesion manualmente en https://externoslof.shiftlabor.com/, luego en
  otra terminal:

  python buscar_y_comparar.py --input mi_lista.xlsx --output reporte.xlsx

Resultado (reporte.xlsx), una fila por colaborador:
  - OK            -> todo coincide
  - ADVERTENCIA   -> el RUT existe pero algun dato no coincide (detalla cual)
  - NO_ENCONTRADO -> el RUT no existe en ShiftLaboral


3. EJECUTAR FASE 2 - Creacion y edicion (OJO: SI modifica datos reales)
--------------------------------------------------------------------------
Mismo mecanismo, script y .bat distintos:
  1. Doble-click en ejecutar_crear.bat
  2. Mismos pasos de login que Fase 1 (reutiliza el mismo perfil de Chrome,
     asi que si ya iniciaste sesion antes no hace falta hacerlo de nuevo).
  3. Arrastra tu Excel y presiona Enter.
  4. Al terminar, revisa reporte_crear.xlsx

Equivalente manual:

  python crear_o_editar.py --input mi_lista.xlsx --output reporte_crear.xlsx

Por cada fila del Excel, el bot:
  - Si el RUT existe    -> compara contra los datos actuales del formulario
                            y edita solo los campos que difieren.
  - Si el RUT no existe -> crea un colaborador nuevo con todos los datos
                            del Excel.
  - Si el Cargo del Excel no calza exacto con el catalogo real del sitio
    -> omite esa fila completa (ni crea ni edita nada de esa persona).

El reporte final indica, por fila: CREADO, EDITADO (con el detalle de que
campos cambiaron), SIN_CAMBIOS, OMITIDO_CARGO o ERROR.

IMPORTANTE: antes de correr Fase 2 contra datos reales de produccion, probar
primero con 2-3 filas de prueba, observando visualmente que el guardado
(boton Guardar) funciona como se espera - este es el unico paso que aun no
se ha validado en vivo.


4. FORMATO DEL EXCEL DE ENTRADA
---------------------------------
Columnas requeridas (nombres exactos, primera hoja del archivo):

  RUT | NOMBRES | apellidoPaterno | apellidoMaterno | SEXO | AFP | ISAPRE |
  sueldoBase | PROVEEDOR | CARGO | TIENDA

Para Fase 2 ademas se necesitan: fechaContratacion y fechaTermino.

PROVEEDOR, CARGO y TIENDA pueden traer el prefijo "LOGISTICA FALABELLA/"
- el bot lo maneja automaticamente en ambas fases.


5. PROBLEMAS COMUNES
-----------------------
- "No se pudo conectar a Chrome en el puerto 9222"
  -> Verifica que Chrome este abierto con el comando/launcher correcto, y
     que no haya otra ventana de Chrome normal (perfil distinto)
     interfiriendo.

- No encuentra el proveedor / se traba seleccionando el grupo
  -> El texto del dropdown puede no calzar exacto con la columna
     PROVEEDOR. Revisar la funcion seleccionar_grupo_proveedor() en
     shift_common.py.

- ShiftLaboral cambio algo en el sitio
  -> Los selectores estan centralizados al inicio de cada script, seccion
     CONFIGURACION.

- Recordar: el sitio fuerza sesion unica por usuario - no correr varias
  instancias del bot en paralelo con la misma cuenta.
